# Roadmap — une brique à la fois

Chaque tâche doit rester assez petite pour tenir dans un commit lisible et vérifiable.

## Journal

- [x] Ajouter un compteur de caractères à la note.
- [x] Permettre de modifier une entrée existante.
- [x] Ajouter une suppression avec confirmation.
- [ ] Permettre d'épingler une entrée importante.
- [ ] Ajouter des tags libres aux entrées.
- [ ] Filtrer le journal par projet.
- [ ] Rechercher dans le texte des entrées.
- [ ] Ajouter un tri ancien/récent.

## BuildInPublic

- [ ] Générer un brouillon de publication X à partir d'une entrée.
- [ ] Copier le brouillon dans le presse-papiers.
- [ ] Afficher le nombre de caractères du brouillon X.
- [ ] Proposer un format court et un format détaillé.
- [ ] Ajouter un champ « prochaine étape » facultatif.
- [ ] Ajouter un champ « blocage rencontré » facultatif.

## Données locales

- [ ] Exporter le journal en Markdown.
- [ ] Exporter le journal en JSON.
- [ ] Importer une sauvegarde JSON validée.
- [ ] Afficher l'espace local approximativement utilisé.
- [ ] Ajouter une action pour effacer toutes les données avec double confirmation.
- [ ] Documenter le schéma de données et sa version.

## Qualité

- [ ] Ajouter des tests pour le chargement des données invalides.
- [ ] Ajouter des tests pour le formatage des dates.
- [ ] Vérifier et améliorer les contrastes.
- [ ] Ajouter une navigation complète au clavier documentée.
- [ ] Améliorer les messages annoncés aux lecteurs d'écran.
- [ ] Ajouter une feuille de style d'impression.
- [ ] Documenter la compatibilité des navigateurs.
- [ ] Ajouter un changelog versionné.
- [ ] Ajouter une vérification automatique du HTML.
- [ ] Ajouter une vérification automatique du JavaScript.

## Plus tard, seulement si le socle reste simple

- [ ] Rendre l'application installable en PWA.
- [ ] Ajouter un fonctionnement hors connexion via service worker.
- [ ] Ajouter une vue calendrier des jours travaillés.
- [ ] Ajouter un indicateur de régularité sans mécanique culpabilisante.
